# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues, discussions or pull requests.

Report them privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability** (<https://github.com/dalywave/dalywave/security/advisories/new>).
Only the maintainers can see the report.

Include what you can:

- the affected component (server, interface, an app, the ml service, the downloader) and version or commit;
- steps to reproduce or a proof of concept;
- what an attacker can achieve.

Reports are acknowledged as soon as possible, usually within a week. Once a fix is ready, it is
released and the advisory is published, with credit to you unless you prefer otherwise.

## Supported versions

Fixes go into the latest release and the `main` branch. Older versions do not get separate patches,
so keep your server and apps up to date.
