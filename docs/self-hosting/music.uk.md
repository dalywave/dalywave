# Власна музика й сховище без хмари (чернетка)

DalyWave можна встановити собі як «Jellyfin/Plex для музики»: музика — це **власна тека** на сервері,
файли лежать на вашому диску, хмара не потрібна. Каталог Deezer і завантажувач із YouTube — окремі налаштування,
за замовчуванням вимкнені.

## Швидкий старт

```env
# Де сервер зберігає свої файли (обкладинки, копії для слабкої мережі, кліпи): власна тека
DALYWAVE_STORAGE=fs
DALYWAVE_STORAGE_PATH=/data
# Теки з музикою — лише читання, через «:»
DALYWAVE_MUSIC_DIRS=/music
# За замовчуванням обидва вимкнені
DALYWAVE_DEEZER=false
DALYWAVE_DOWNLOADER=false
```

У docker compose: том для `/data` (читання й запис) і тека з музикою в `/music` **лише для читання**
(`- /srv/music:/music:ro`) — і в `api`, і в `worker`. Сервісу аналізу `ml` потрібна адреса API всередині мережі
compose: `DALYWAVE_STORAGE_ML_URL=http://api:8400` (у `worker`).

## Що відбувається з текою

- **Сканування.** `worker` обходить теки під час запуску, раз на 6 годин і за кнопкою «Пересканувати» в
  адмінці («Бібліотека»). Між обходами він стежить за змінами (inotify/FSEvents) і після кількох
  секунд тиші обробляє лише шляхи, що змінилися. На мережевих дисках подій немає — зміни підхопить
  найближчий повний обхід.
- **Теги** читаються як є: назва, виконавці (`feat.` — запрошені, `;` — кілька), альбом, виконавець
  альбому (albumartist), номер трека й диска, рік, жанр, ISRC, MusicBrainz ID, ReplayGain. Чого немає
  в тегах — береться зі шляху `Виконавець/Альбом/01 Назва.flac`.
  Збірки (albumartist «Various Artists» або прапорець compilation) об’єднуються під «Various Artists».
- **Обкладинки:** вбудована у файл, інакше `cover.jpg`, `folder.jpg`, `front.jpg` … у теці альбому.
- **Зміни:** файл із тим самим розміром і часом зміни не перечитується. Нові теги — той самий трек із
  новою назвою. Перейменування й перенесення в іншу теку розпізнаються за відбитком початку файлу:
  вподобання, плейлисти й історія лишаються. Видалений файл зникає з медіатеки разом з альбомом і
  виконавцем, якщо від них нічого не лишилося. Недоступна тека (диск не змонтовано) нічого не видаляє.
- **Нічого не копіюється й не перекодовується.** FLAC, MP3, AAC (M4A), Vorbis і WAV віддаються як є.
  ALAC, AIFF, Opus в Ogg, APE, WavPack і Musepack відтворюють не всі браузери — для них під час першого
  відтворення робиться копія (без втрат — FLAC, із втратами — AAC 256 кбіт/с); копії зберігаються в
  сховищі й вичищаються, коли їх більше за `DALYWAVE_RENDITIONS_MAX_GB` (20 ГБ).
- **Гучність і форма хвилі** обчислюються для кожного файлу (ffmpeg), потім запис іде на аналіз звуку
  (`ml`): темп, тональність, настрій, переходи — для «Моєї хвилі» і плавних переходів.
- WMA, DSD і пошкоджені файли до медіатеки не потрапляють — їх видно в адмінці з причиною.

## Сховище

`DALYWAVE_STORAGE=fs` (власна тека, файли віддає сам API за короткими підписаними посиланнями з Range) або
`DALYWAVE_STORAGE=s3` (R2, MinIO, SeaweedFS) — докладно в [storage.uk.md](storage.uk.md).

## Каталог Deezer — `DALYWAVE_DEEZER=true`

Пошук у всьому каталозі, чарти, новинки, схожі виконавці, повні сторінки виконавців, розвідник нової
музики для хвилі. Файли з теки зіставляються з Deezer (ISRC, потім назва, виконавець і
тривалість): у знайдених — обкладинки у високій якості й схожі. Без Deezer усе працює на тегах:
пошук — у вашій музиці, хвиля й рекомендації — теж на ній, імпорт плейлистів зіставляє треки
з тим, що є на сервері.

## Завантажувач — `DALYWAVE_DOWNLOADER=true`

Завантаження записів з YouTube (завантажувач на Mac або серверний fetcher), «Спірні», дозавантаження релізів за
підписками, кліпи. **Завантаження з YouTube може порушувати його правила використання** — вмикайте,
розуміючи це, і лише для себе. Без завантажувача трек, якого немає на сервері, просто не грає.

## Перевірка на тестовій теці

Тека з 41 файлу (FLAC 16/44 і 24/96, MP3 із вбудованою обкладинкою, AAC, ALAC, Vorbis, Opus, WAV без тегів,
AIFF, пошкоджений MP3, WMA; кирилиця в тегах і шляхах) на чистій базі: сканування ~2,5 с, усі 39 треків грають,
копії для ALAC/Opus/AIFF робляться за секунди, форму хвилі має кожен, перенесення файлу зберігає вподобання.
