# Своя музыка и хранилище без облака (набросок)

На украинском: [music.uk.md](music.uk.md)

DalyWave можно поставить себе как «Jellyfin/Plex для музыки»: музыка — это **своя папка** на сервере,
файлы лежат на своём диске, облако не нужно. Каталог Deezer и загрузчик с YouTube — отдельные настройки,
по умолчанию выключены.

## Быстрый старт

```env
# Где сервер хранит свои файлы (обложки, копии для слабой сети, клипы): своя папка
DALYWAVE_STORAGE=fs
DALYWAVE_STORAGE_PATH=/data
# Папки с музыкой — только чтение, через «:»
DALYWAVE_MUSIC_DIRS=/music
# По умолчанию оба выключены
DALYWAVE_DEEZER=false
DALYWAVE_DOWNLOADER=false
```

В docker compose: том для `/data` (чтение и запись) и папка с музыкой в `/music` **только на чтение**
(`- /srv/music:/music:ro`) — и у `api`, и у `worker`. Сервису анализа `ml` нужен адрес API внутри сети
compose: `DALYWAVE_STORAGE_ML_URL=http://api:8400` (у воркера).

## Что происходит с папкой

- **Сканирование.** Воркер проходит папки при запуске, раз в 6 часов и по кнопке «Пересканировать» в
  админке («Библиотека»). Между проходами он следит за изменениями (inotify/FSEvents) и через несколько
  секунд тишины разбирает только изменившиеся пути. На сетевых дисках событий нет — их подхватит
  ближайший полный проход.
- **Теги** читаются как есть: название, исполнители (`feat.` — приглашённые, `;` — несколько),
  альбом, исполнитель альбома (albumartist), номер трека и диска, год, жанр, ISRC, MusicBrainz ID,
  ReplayGain. Чего нет в тегах — берётся из пути `Исполнитель/Альбом/01 Название.flac`.
  Сборники (albumartist «Various Artists» или флаг compilation) собираются под «Various Artists».
- **Обложки:** встроенная в файл, иначе `cover.jpg`, `folder.jpg`, `front.jpg` … в папке альбома.
- **Изменения:** файл с теми же размером и временем изменения не перечитывается. Новые теги —
  тот же трек с новым названием. Переименование и перенос в другую папку узнаются по отпечатку начала
  файла: лайки, плейлисты и история остаются. Удалённый файл уходит из медиатеки вместе с альбомом и
  исполнителем, если от них ничего не осталось. Недоступная папка (диск не смонтирован) ничего не удаляет.
- **Ничего не копируется и не перекодируется.** FLAC, MP3, AAC (M4A), Vorbis и WAV отдаются как есть.
  ALAC, AIFF, Opus в Ogg, APE, WavPack и Musepack браузеры играют не все — для них при первом
  воспроизведении делается копия (без потерь — FLAC, с потерями — AAC 256 кбит/с); копии лежат в
  хранилище и вычищаются, когда их больше `DALYWAVE_RENDITIONS_MAX_GB` (20 ГБ).
- **Громкость и форма волны** считаются по каждому файлу (ffmpeg), затем запись уходит на анализ звука
  (`ml`): темп, тональность, настроение, переходы — для «Моей волны» и плавных переходов.
- WMA, DSD и битые файлы в медиатеку не попадают — они видны в админке с причиной.

## Хранилище

`DALYWAVE_STORAGE=fs` (своя папка, файлы отдаёт сам API по коротким подписанным ссылкам с Range) или
`DALYWAVE_STORAGE=s3` (R2, MinIO, SeaweedFS) — подробно в [storage.md](storage.md).

## Каталог Deezer — `DALYWAVE_DEEZER=true`

Поиск по всему каталогу, чарты, новинки, похожие артисты, страницы артистов целиком, разведчик новой
музыки для волны. Файлы из папки сопоставляются с Deezer (ISRC, затем название, исполнитель и
длительность): у найденных — обложки в высоком качестве и похожие. Без Deezer всё работает на тегах:
поиск — по своей музыке, волна и рекомендации — по ней же, импорт плейлистов сопоставляет треки
с тем, что есть на сервере.

## Загрузчик — `DALYWAVE_DOWNLOADER=true`

Скачивание записей с YouTube (загрузчик на Mac или серверный fetcher), «Спорные», докачка релизов по
подпискам, клипы. **Скачивание с YouTube может нарушать его правила использования** — включайте,
понимая это и только для себя. Без загрузчика трек, которого нет на сервере, просто не играет.

## Проверка на тестовой папке

Папка из 41 файла (FLAC 16/44 и 24/96, MP3 с встроенной обложкой, AAC, ALAC, Vorbis, Opus, WAV без тегов,
AIFF, битый MP3, WMA; кириллица в тегах и путях) на чистой базе: скан ~2,5 с, все 39 треков играют,
копии для ALAC/Opus/AIFF делаются за секунды, форма волны есть у каждого, перенос файла сохраняет лайк.
