# Спайк аудиодвижка на iPhone: установка из Xcode

Минут 15. Нужны Mac с Xcode 27.2 и Rust, iPhone с кабелем и одна сеть Wi‑Fi для Mac и iPhone.

## 1. Тестовый сервер на Mac

```sh
cd ~/Documents/Develop/SideMusic/spikes/ios-audio
python3 tools/gen_audio.py          # один раз, если нет папки testdata (нужен ffmpeg)
python3 tools/serve.py --port 8420  # держите открытым, пока проверяете
```

Адрес Mac в сети — `ipconfig getifaddr en0` (например `192.168.1.10`). Если macOS спросит, разрешить ли Python входящие соединения, — «Разрешить».
Проверка с iPhone: Safari → `http://<адрес Mac>:8420/manifest.json` должен открыть JSON.

## 2. iPhone

1. Подключите кабелем, на iPhone — «Доверять этому компьютеру».
2. Включите режим разработчика: «Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика» → вкл., перезагрузка, подтвердить. Пункт появляется после первого подключения к Xcode — если его нет, сделайте шаг 3 и вернитесь.

## 3. Xcode

```sh
open ~/Documents/Develop/SideMusic/spikes/ios-audio/app/src-tauri/gen/apple/dw-spike.xcodeproj
```

1. Слева проект `dw-spike` → цель `dw-spike_iOS` → вкладка «Signing & Capabilities»: включено «Automatically manage signing», Team — **Zakhar Stupak (Y5KR5JPCRG)**, Bundle Identifier — `rest.daly.wave.spike`. Если команды нет в списке: Xcode → Settings → Accounts → «+» → Apple ID.
2. Сверху: схема **dw-spike_iOS**, устройство — ваш iPhone.
3. ⌘R (Product → Run). Первая сборка 2–5 минут: фаза «Build Rust Code» собирает Rust-ядро (`build-ios.sh`), схема собирает release.
4. Если iPhone пишет «Ненадёжный разработчик»: «Настройки» → «Основные» → «VPN и управление устройством» → ваш профиль → «Доверять». Запустите снова.

Без кабеля: после первой установки по кабелю в Xcode → Window → Devices and Simulators → iPhone → «Connect via network»; дальше ⌘R работает по Wi‑Fi.

## 4. В приложении

1. При первом запуске iOS спросит доступ к локальной сети — «Разрешить».
2. В блоке «Что играть» введите `http://<адрес Mac>:8420` → «Подключить». Появятся наборы.
3. Громкость на телефоне — нормальная (движок играет на полной громкости по умолчанию).

## 5. Что проверить (и что должно быть)

| # | Действие | Ожидание |
|---|---|---|
| 1 | «Длинная очередь для фона» | Звук меньше чем через 0,3 с (бейдж «Звук через N мс»); треки идут подряд без пауз (смена форматов Opus/FLAC/MP3/AAC) |
| 2 | Заблокировать телефон | Музыка продолжается. На экране блокировки — карточка: «Part N · формат», «DalyWave Test Signals», обложка-градиент, прогресс |
| 3 | Кнопки на экране блокировки: пауза, играть, следующий, предыдущий | Работают; «предыдущий» в первые 3 с — прошлый трек, позже — к началу трека |
| 4 | Перетащить ползунок прогресса на экране блокировки | Перемотка туда же |
| 5 | Оставить заблокированным на 2–3 минуты | Играет всё время, треки меняются сами |
| 6 | Пункт управления (свайп с правого верхнего угла) | Та же карточка, кнопки работают |
| 7 | Наушники (проводные или AirPods): играть → снять/выдернуть | Пауза. Надеть и нажать на наушниках — играет |
| 8 | Звонок (попросите позвонить или FaceTime-аудио), ответить, положить трубку | Во время звонка пауза; после — само продолжает (если iOS разрешит возобновление) |
| 9 | Будильник/таймер, Siri | Пауза и возврат, как у звонка |
| 10 | «Самопроверка стыков» → «Запустить» | Все строки зелёные, «0 diff, len +0» (WebM и Vorbis — известные ограничения, см. REPORT.md) |
| 11 | «Переходы» → «Кроссфейд», 6 с → «Demo pieces» | Плавное наложение треков; громкость тихой пьесы «Quiet Hour» выровнена |
| 12 | Свернуть приложение и открыть другое | Играет |

Блок «Нагрузка» на странице показывает CPU процесса, память, загрузку аудиоколбэка и недогрузки — запишите значения при воспроизведении FLAC 24/96 («Gapless · flac24_96»).

## 6. Журнал

Журнал пишется в контейнер приложения: Xcode → Window → Devices and Simulators → iPhone → Installed Apps → DalyWave Spike → «…» → Download Container → внутри `AppData/Library/Application Support/rest.daly.wave.spike/dw-spike.log`. Последние строки видны внизу страницы приложения. В журнале по строкам `remote command: …`, `session: …`, `app entered BACKGROUND`, `pos #…` видно, что дошло до движка.

## Если что-то не так

- **«cargo: command not found» в фазе Build Rust Code** — Rust ставится через rustup в `~/.cargo/bin`; скрипт добавляет этот путь сам. Проверьте `ls ~/.cargo/bin/cargo`.
- **Ошибка подписи «No profiles for 'rest.daly.wave.spike'»** — в Signing & Capabilities выберите команду ещё раз; Xcode создаст профиль сам (устройство должно быть подключено).
- **Сервер недоступен** — Mac и iPhone в одной сети; разрешите Python во входящих (Системные настройки → Сеть → Файрвол); проверьте `manifest.json` в Safari на телефоне.
- **Тишина** — проверьте громкость и куда идёт звук (Bluetooth). Переключатель «Без звука» сбоку на воспроизведение не влияет — так и должно быть для категории playback.
- **Пересобрать Xcode-проект** — `cd app/src-tauri/gen/apple && xcodegen generate`. Не запускайте `cargo tauri ios init` заново: он перезапишет проект и вернёт штатную фазу сборки Tauri, которая работает только при запущенном `tauri ios dev`.
